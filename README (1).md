# Customer Behavior Dashboard

## Project Overview
Customer Behavior Dashboard is an end-to-end Data Analytics project built using Excel, Python, MySQL, and Power BI.  
The project focuses on analyzing customer shopping behavior and transforming raw retail data into meaningful business insights through an interactive dashboard.

---

## Dashboard Preview

![Customer Behavior Dashboard](dashboard_preview.png)

---

## Project Objectives
- Analyze customer purchasing behavior
- Identify profitable customer segments
- Track seasonal sales performance
- Improve customer retention strategies
- Automate the data analytics pipeline

---

## Tools & Technologies Used
- Microsoft Excel
- Python
- pandas
- MySQL
- Power BI Desktop

---

## Project Workflow
1. Customer shopping data stored in Excel
2. Python reads and cleans the dataset
3. Data inserted into MySQL database
4. Power BI connected with MySQL
5. Interactive dashboard created for analysis

---

## Key Insights
- Total Customers: 3.9K
- Average Purchase Amount: $59.76
- Average Review Rating: 3.75/5
- Clothing category generated highest revenue
- Free Shipping was the most preferred shipping method
- 73% customers were non-subscribers
- Young Adults contributed highest revenue

---

## Business Findings
- Clothing category has high sales but lowest customer rating
- Fall season generated highest sales
- Subscription benefits need improvement
- Free shipping strongly influences customer purchases

---

## Challenges Faced
- Inconsistent Excel data formatting
- Missing Age Group column

---

## Final Result
A fully interactive Power BI dashboard connected with MySQL that automatically updates whenever new Excel data is loaded through the Python pipeline.
